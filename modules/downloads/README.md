# 下载管理

独立 `ApplicationModule`，通过公共模块界面接入。aria2 是固定版本的外部传输依赖，不另建 AI 会话或任务调度器。

## 使用

1. 执行 `python -m tools.setup_download_dependencies` 安装并校验官方便携 aria2 1.37.0；不会全局安装。
2. 打开 **设置 → 应用模块 → Downloads → 配置**，将 `enabled` 改为 `true` 并保存。配置在下一次正常启动服务时生效。
3. 在此模块中选择 **查看活动 → 新增下载**，填写名称、直链或磁力链接。直链可指定保存文件名和 SHA-256。
4. 任务提供暂停、继续或核对、取消传输。取消保留已有文件；程序重启保留记录，未完成项需手动继续。

默认关闭。启动模块也不会立即运行引擎，首次明确新增或继续下载才启动自身的 aria2。配置也可通过产品 CLI 的 `downloads init|status|enable|disable` 管理；CLI 的状态是配置期望值，实际状态以原生模块目录为准。

配置字段：`maxConcurrent`（1–3，默认 3）、`perDownloadLimit`（每任务字节/秒，默认 5242880）、`reserveBytes`（受理时最低剩余空间，默认 5 GiB）、`enableDht`（默认开启）。同一时刻只控制自己启动的引擎，不连接或接管旧 aria2。

## 数据和行为

- 使用原生插件 KV 的自身命名空间保存受理、操作及任务记录，没有第二个任务数据库。先持久化受理，再调用引擎；相同请求不会重复提交。
- 未确认的操作保留请求标识，先核对状态。意外退出后不自动重放网络传输。缺失续传控制信息时保留文件并报告错误，不允许覆盖。
- 文件只写入模块自身 `files/<任务标识>/`。不接受任意目录、程序、RPC 地址或账号字段。
- 界面打开且可见时才读取约每秒一次的进度；后台仅接收自身引擎事件。百分比来自 aria2 的有效字节数，不使用预分配文件大小。磁力元数据完成不等于文件下载完成。
- 完成通知通过原生通知接口幂等保存。通知失败不会重做下载；模块停用释放自己的资源，不阻塞普通会话或 QQ。

本期提供直链与磁力的受理和管理，不包含资源搜索、候选测速择优、播放器导入或旧任务迁移。真实直链、校验失败、暂停续传、取消和重启已经通过回环来源验证；磁力仅验证实际引擎受理及取消，未宣称真实公网 BT 文件下载验收通过。

验收入口：`python tools/run_runtime_checks.py --task W1-01`。依赖版本及来源见 `upstream/aria2.json`；二进制、下载文件、凭据和运行日志不提交。
