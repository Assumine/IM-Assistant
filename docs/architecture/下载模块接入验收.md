# 下载模块接入

使用固定官方 aria2 1.37.0，作为模块的依赖，不作为单独业务插件。下载数据、受理记录、分片与引擎资源由 modules/downloads 持有；OpenCode 继续拥有会话、Inbox 和原生客户端。无 QQ 登录依赖，不读取旧影片、下载账户或原控制器状态。

- [ ] E01 公共模块操作接口仅调用当前激活的可信模块，输入输出有界，关闭取消在途操作，旧按钮不能调用已停用资源；核心不知道下载字段。
- [ ] E02 真实 aria2 回环直链下载、最终内容校验、暂停/继续/取消及磁力受理通过；元数据完成不能冒充文件完成，进度不能来自预分配文件大小。
- [ ] E03 持久受理先于外部操作，同一请求不重复创建；未知结果需核对，重启保留记录/分片且不自动重放，文件只写受控自有目录。
- [ ] E04 构建后的原生模块界面提供中文表单/操作、真实进度与失败反馈；隐藏/关闭停止进度读取，拒绝迟到结果，未知受理保留同一请求标识。
- [ ] E05 产品组合、依赖校验、配置及模块故障隔离验证，不影响正常会话和原有 QQ/研究关闭状态；证据脱敏且不上传文件、日志或凭据。

本期做下载与管理，不把旧影视推荐、站点搜索、QQ 授权或另一个调度器迁入。自动候选测速/择优、播放器导入与真实公网 BT 完整传输仍须后续单独验收。取消默认只停传输，保留已取得文件；不隐式删除用户数据。
验收定义保持未勾选；执行状态统一见 progress.json 与 tests/modules/downloads-evidence.json。本期 E01–E05 已完成隔离运行验收。
