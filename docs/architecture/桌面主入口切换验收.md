# 桌面主入口切换

本轮用户明确授权：“可以替换现有的助手的位置了”。范围为当前用户的主启动入口、原登录启动项与新版原生窗口；不是旧数据库、模型凭据、QQ账号或可执行任务的迁移。

- [ ] D01 先核实旧助手无在途进程，保存原快捷方式及计划任务的可恢复副本；只更新明确属于旧助手的入口，无关浏览器、CPU传感器和其他软件不变。
- [ ] D02 使用最新构建和固定工具链打开原生新版，独立F盘资料目录，验证服务、可用窗口和重复启动复用；不自动登录QQ、调用模型或重放旧任务。
- [ ] D03 从实际系统入口回读切换结果，验证原自启动项、桌面/开始菜单及回退备份；公开证据脱敏，私人备份、注册信息和日志只留本地。

用户补充“汉化包不全”，作为独立本地化验收，不改变已授权的入口切换范围。

- [ ] D04 简体中文覆盖锁定版本的应用、共享组件和所有内置 GUI 插件的英文键，插值变量完整，英文语义源不改写。
- [ ] D05 实际构建界面中切换语言，模块、后端、用量页同步更新，重新加载保留语言，并能切回英文。
- [ ] D06 更新并重新打开实际主入口窗口，核对简体中文设置和可用输入；记录验证命令、用语审核和尚未迁入的业务边界。

旧版目录与资料保留。回退先关闭新版窗口，再恢复原入口及计划任务；不把新版已接收任务复制回旧版。模块的真实账号、历史和未迁完业务继续单独验收。当前用户授权覆盖本轮入口切换，不授权后续自动迁移私人数据。
