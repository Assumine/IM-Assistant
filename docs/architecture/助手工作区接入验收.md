# 助手工作区

OpenCode 继续拥有原生会话、Inbox、数据和执行；助手主导航独立于设置，通过公共 ApplicationPage 接纳完整业务页面。页面注册、导航和错误隔离归核心；总览、模块操作和通知呈现归能力 GUI 插件。QQ 仍是可选接口，不成为软件启动前提。

视觉沿用炭黑灰白和现有字体变量：深底 #202020、内容 #191919、层级 #262626、边界 #303030、正文 #dcdcdc、辅助 #a2a2a2；颜色通过已有语义 token 使用。固定图标侧栏，主区左对齐；总览使用紧凑功能行和待处理通知，业务页直接展示操作。避免装饰卡片、介绍段落和常驻指标轮询。

- [ ] F01 侧栏业务入口打开独立页面，支持刷新/前进后退及正确选中；配置仍进入设置，日常使用无需穿过设置页。
- [ ] F02 助手默认首页展示真实模块状态和待办入口，会话是并列入口；会话/Inbox/后端执行仍由原生层持有，不创建第二套任务队列。
- [ ] F03 模块页面直接呈现其业务视图，未启用/断线/失败如实反馈；离开页面释放读取，模块或页面故障不阻塞其他导航；中文与窄屏布局通过构建界面验收。

不借本次界面修改启用 QQ 账号、导入旧数据或重放任务。业务覆盖不足应明确记录，不能用空模板冒充已经接回旧助手的全部功能。
