# 助手地基重构设计

本次方案以接入一整套会话后端为单位。OpenCode 是默认参考实现，Codex 原生系统是未来同级接入方；各自的历史、上下文、压缩、工具和队列留在后端内部。宿主提供统一入口和展示，不要求把这些内部机制拆成独立插件。

范围仅限地基。本目录不被生产模块扫描，不包含已安装的运行配置，也不修改当前业务模块或运行任务。

| 文件 | 用途 |
| --- | --- |
| [重构方案](重构方案.md) | 架构、职责、所有权、隔离、数据、建设顺序和回滚 |
| [接口契约](接口契约.md) | 完整后端的最小接口、可选能力、输入与事件语义 |
| [实施与验收](实施与验收.md) | P0 至 P4 的实施范围及66项待实施验收 |
| [范围记录](scope.json) | 当前决策与明确留到后续的模块事项 |
| [包清单规范](contracts/module-manifest.schema.json) | 完整包的静态发现与运行声明 |
| [后端描述规范](contracts/backend-descriptor.schema.json) | 一个完整后端的所有权、方法和能力 |
| [事件规范](contracts/backend-event.schema.json) | 来源事件关联、顺序及去重身份 |
| [OpenCode 后端示例](examples/opencode-backend.json) | 参考设计，不代表当前生产能力的实测结果 |
| [另一套原生后端示例](examples/native-system-backend.json) | 展示不同原生系统如何保持同级接入 |
| [完整包示例](examples/module-manifest.json) | 单个入口接入整套系统，无压缩器等独立必装包 |
| [事件示例](examples/backend-events.json) | 接纳、应用、结果与结束的先后关系 |

在仓库根目录安装开发依赖后，运行 `python tools/validate_design.py` 可校验这些设计文件，无需启动后端或调用模型。校验结果保存在不提交的 `.reports/`。当前代码依据指向旧工作区，仅作设计参考，不属于本仓库已实现代码。

当前交付为设计。66项运行验收仍全部待实施，正式接入与生产迁移没有在本轮执行。
