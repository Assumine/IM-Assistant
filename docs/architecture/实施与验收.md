# 基于 OpenCode 的实施验收

当前plan_id为opencode-app-base-v2，共36项新路线验收。完成状态只在progress.json记录；复选框用于列出要求，不独立维护进度。旧P0的49项参考测试不计入本清单。

先执行原生未改造基线，再以同一锁定版本验证产品改造。原生测试、隔离模型、真实网页、Windows桌面和生产切换分别记录，不互相替代。

## R0 原生源码基线

- [ ] A01 正式源码tag/commit、依赖锁、工具链、许可证及版权可核对，开发分支调研不冒充正式锁定。
- [ ] A02 隔离环境下未改造网页和Windows桌面真实构建/启动，通过原生输入、Inbox、历史和重启基线。
- [ ] A03 原生应用不依赖QQ、Agent2API和旧助手数据；没有模型凭据仍可进入设置和明确空态。

## R1 助手模式与去文件能力

- [ ] A04 启动助手不要求选择项目或真实Git工作区，必要Location在应用管理的非项目环境内。
- [ ] A05 会话、Inbox、历史和上下文只由原生数据访问管理，助手扩展不创建竞争权威库。
- [ ] A06 新应用数据、应用ID、端口和凭据配置与旧应用隔离，重启后设置及原生身份稳定。
- [ ] A07 项目文件树、编辑、diff、终端及Git/worktree等编码入口从助手产品移除。
- [ ] A08 项目读写/检索/补丁和通用命令工具实际不可调用，直接API、MCP和子代理也不能绕过。
- [ ] A09 不扫描用户项目、不读取项目指令或启动项目文件监视；后台无隐含项目加载。
- [ ] A10 内部数据库迁移、配置、历史、受控附件上传/预览与导入导出保持可用，业务服务无任意路径能力。

## R2 原生会话、API和用量

- [ ] A11 空闲发送原生接纳并展示，不先显示错误排队又弹回；忙碌输入按真实回执立即可见。
- [ ] A12 最后结果、结束与下一输入按原生顺序显示，不依赖通知完成，不等第一条AI回复判断接纳。
- [ ] A13 队列引导、调序和撤回指向正确原生输入，冲突显示真实结果，只有运行项时不显示队列0。
- [ ] A14 切换会话、刷新和重新订阅不暂停执行或转移未回复消息，不产生双重发送。
- [ ] A15 历史首显、分页锚点、消息顺序和输入归属稳定，不被旧缓存覆盖或跳到顶部。
- [ ] A16 历史不重播弹入，新消息只一次；发送、队列和历史控制来自原生实现而非重写状态机。
- [ ] A17 受支持的兼容API可配置、查询模型并生成；Agent2API只是可选API地址，探测与生成分别验证。
- [ ] A18 账号/连接/模型变更的生效范围可验证，旧输入不静默转移；凭据不进入日志和公开消息。
- [ ] A19 原生用量/上下文数据真实，今天/7天/累计和缓存口径明确，未报告不置零，套餐不虚构费用。

## R3 原生Codex与QQ接口

- [ ] A20 Codex原生线程、账号、历史、上下文和压缩得以保留，不被伪装成无状态模型调用。
- [ ] A21 每条会话只有一个执行队列权威，桥接不重复认领、不运行第二层Agent循环。
- [ ] A22 原生执行器适配不绕过助手文件禁用；无法满足时不发布不兼容入口，外部旧系统不被修改。
- [ ] A23 QQ缺失、未登录、断线或登录失败不影响应用启动、普通会话和其他能力状态展示。
- [ ] A24 绑定、授权、引用与任务/输入映射正确；当前调整、排队补充及新任务不会发送到错误会话。
- [ ] A25 历史留言去重、队列撤回及回执撤回走唯一原生输入链，首轮/最终引用与原消息对应。
- [ ] A26 群/私聊及小羊规则隔离，通知结果未知只核对发送，不重跑任务或阻塞下一项。

## R4 能力位置与视觉

- [ ] A27 保持核心框架＋插件；能力使用原生插件/GUI/RPC及公共展示位置，业务不硬编码进核心，依赖不混作功能插件；产品补丁有来源与回归，不建立第二个宿主。
- [ ] A28 任一可选模块启动失败不连带停止会话，业务服务可独立停用，空模块应用仍可运行。
- [ ] A29 通知未读与人工待处理分开，读后清除未读；硬件/进程监控仅在需要时启动。
- [ ] A30 助手布局、图标、字体/DPI、窗口缩放、长列表及骨架在真实网页/桌面稳定。
- [ ] A31 主题和有限动效修改前后的原生交互回归一致，不改变排队时机、顺序和消息归属。
- [ ] A32 原生网页、真实浏览器和Windows桌面分别验证，不依赖旧WebView壳或旧服务器。

## R5 整体与切换

- [ ] A33 原生基线、产品补丁和旧问题回归都有可重跑证据，历史P0测试不计新版完成。
- [ ] A34 崩溃、断网、重复事件、限流和未知回执不造成重复执行；恢复及通知解耦正确。
- [ ] A35 同样本比较启动、历史、回执和空闲开销，监控按需，无未经测量的性能改善声明。
- [ ] A36 迁移/回退有唯一接纳所有者与数据核对，不覆盖生产库、不重放已接纳输入，不自动切换自启。
