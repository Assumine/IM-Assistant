# 新接手 AI 的起步说明

当前采用 **OpenCode完整应用二次开发**。基座计划 opencode-app-base-v2 已完成，当前推进 qq-plugin-migration-v1 独立聊天插件阶段。旧“Python宿主+OpenCode后端”的实施路线已归档，不能继续旧P1任务。

整体架构仍为核心框架＋插件：OpenCode作为应用/会话核心基础，助手业务以完整能力插件接回。实现前先按方案第3节核对层次、原生状态所有者和依赖方向；不能因为某个需求难适配，就另建核心宿主、硬编码业务或由插件接管全局发送/队列。

## 开始前

1. 读取根 AGENTS.md、[完整方案](../architecture/重构方案.md) 和 [决策](决策与外部前提.md)。
2. 读取 work-plan.json 和 progress.json；根plan_id保留基座，两者module_plan为后续阶段，progress.active_plan_id决定当前计划。
3. 运行 python tools/next_task.py --json；默认返回当前QQ阶段下一项，不继承基座完成数；不要自动复活旧P0/P1任务。
4. 读取 [依赖/源码证据](dependency-baseline.json) 与当前任务。当前正式基线为 v2.2.3；dev快照和原SDK2.1.4只保留为历史参考。
