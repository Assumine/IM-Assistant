# 简体中文语言包审核

本轮补齐锁定 OpenCode 2.2.3 中应用、共享组件及内置 GUI 插件的 938 个缺失键，另修正原有英文占位提示、调试标签及通知区默认可访问名称。英语语义源保留原值；通知区只新增对应原依赖默认值的翻译键。传统中文及其他语言未批量改写。

统一用语：会话、队列、上下文、压缩、提供商、模块、后端、缓存命中率、用量、启用/停用。用量统计的“今天/最近 7 天/累计”及未知/未上报区别沿现有原生统计事实，不把缺失数据翻译成零消耗。

核对语料：[Microsoft VS Code 简体中文](https://github.com/microsoft/vscode-loc/blob/main/i18n/vscode-language-pack-zh-hans/translations/main.i18n.json)、[Mozilla Firefox 简体中文设置](https://github.com/mozilla-l10n/firefox-l10n/blob/main/zh-CN/browser/browser/preferences/preferences.ftl)及[浏览器用语](https://github.com/mozilla-l10n/firefox-l10n/blob/main/zh-CN/browser/chrome/browser/browser.properties)。数量选择沿原生 Intl/CLDR 机制，中文仍提供所需模板，不在组件里添加中文判断。

已逐项审查保留英文：OpenCode 等品牌/提供商名称，PDF/MCP/LSP/WSL/SSH/FPS/TPS/INP/CLS 等缩写，Bash/Shell/Glob/Grep/Webfetch 等实际工具名称，示例 URL/SSH 命令、键盘图例、音效资产名、字体/外部应用名称及纯变量模板。这些不是缺译。服务器返回的用户内容、错误原文和模型标识不做盲目替换。

19 份实际字典的键集合与插值模板由现有 language.test.ts 验证；真实构建的 settings keeper 验证语言即时切换、懒加载插件、数量文案、刷新保留和英文回切。原生桌面窗口另行人工观察，明确与确定性浏览器夹具分开记录。不宣称核验每个第三方服务返回的动态文本。
