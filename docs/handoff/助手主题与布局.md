# 助手主题与有限动效

R4-02在原生应用上换肤，普通会话、整套后端、Inbox、历史和设置继续由原生机制管理。视觉范围仅助手的非项目模式，原版项目模式和用户选择的其他配色保留。

## 设计约束

浅色模式沿用助手方向：云白#F5F8FA、纸白#FFFFFF、深蓝灰#17313E、次级蓝灰#5D7481、青色#008B9D、分隔线#DCE6EB。深色按用户最新参考改为炭黑#191919、外栏深灰#202020、层次灰#262626/#303030、灰白文字#DCDCDC和中性灰白选中态；不使用蓝青底色、青色高亮或彩色阴影。成功、警告、失败保留原生语义色，用户主动选择的其他主题继续生效。

字体沿用原生UI/代码/终端三种用户字体角色，不打包新字体。界面正文14px、阅读正文15px、标题18px左右，使用20px以上正文行高；不通过整页CSS zoom伪造DPI。Windows标题栏继续保留原生关闭/最大化/最小化区域和按实际缩放计算的留空。

布局重点是固定图标导航与整块内容之间的单一分隔线。左侧图标导航跨Home、会话与设置保持位置；会话标签、列表、排序和切换仍使用原生实现。窄窗口压缩装饰留白，不缩小文字；手机保留原生顶部/底部栏和抽屉，不堆放一列挤占正文的导航。

```text
┌ 原生标签栏与窗口控制 ────────────────────────┐
│ 图标 │ 原生会话列表（用户选择竖排时）│ 当前内容 │
│ 导航 │ 可折叠、可调整宽度          │ 原生侧面板│
│      │                            │ 与输入区域│
│ 设置 │                            │           │
└──────┴────────────────────────────┴───────────┘
```

不增加装饰性卡片墙、背景渐变、全页进入动画或hover缩放。原生数据未加载完成的占位保持相同布局；侧栏与内容不各加一重圆角外壳。主题通过语义变量、稳定布局属性和小范围组件样式接入。

## 动效边界

只为新到的文字消息提供一次短入场，为原生处理中状态保留原指示器，为真实进度提供进度变化。历史首载、向前分页、缓存恢复、会话切换和虚拟行重新挂载均不能重放消息入场。动画只改变透明度和局部位移，不决定消息排序、测量高度或等待队列执行。

减少动态效果继续读取原生设置/系统偏好；新消息在该模式直接显示。隐藏或不活动的会话不为了动效维持额外轮询。不会改写原生发送、引导、撤回、分页和执行时机。

## 验证方法

先记录换肤前相同原生交互和非项目会话的生产构建性能，再使用同一样本比较。现有重型代码工作区基准不能直接当作助手样本；早期试跑在初始底部锚点检查未通过，保留为失败诊断，不计为性能基线。

用原生E2E keeper验证布局与历史/队列交互，实际Chromium验证不同尺寸、缩放和减少动态效果；Windows Electron使用独立测试资料和真实窗口/缩放接口验收。构建通过不等于桌面布局通过。真实账号、私人历史、旧客户端不作为测试数据。

## 实际验收

R4-02正式入口通过3项编排验收。换肤前后同名57项原生队列/历史用例全部通过；新增布局、动效和外观设置3个keeper各执行5次，共15次。合计72次浏览器执行及69项原生数据/目录清单测试，零失败、零跳过、零重试，另有前后各3次生产构建性能测量。原生HTTP/SQLite链路真实接纳、引导、撤回、排队、空闲发送与重启，执行4次回环模型请求；不使用真实模型或QQ。

本机两会话、每会话40条消息、相同串行生产样本：首次完整显示中位数由93.7ms变为93.9ms，稳定显示由127.3ms变为125.3ms。三次样本仅作本机描述性参考，不声称普遍提速或覆盖完整启动/空闲开销。

实际Windows Electron使用全新隔离资料启动原产品入口。深色按用户最新参考使用炭黑、层次深灰与灰白选中态；系统DPI144（150%），通过原生IPC切换应用100/110/125/150%缩放，实际调整1280×820、960×680窗口并最大化；标题栏控制区域、内容与输入框未越界。未修改系统DPI；其他系统DPI、其他Windows用户、其他OS和安装包尚未验证。

发现并修复非项目助手仍查询VCS、工作树、Shell、MCP及旧项目迁移状态的初始化403。原生Data按宿主工作区模式跳过项目目录读取，原生目录清单在关闭时不枚举或刷新；默认项目模式行为保留。实际窗口操作零被拒绝请求；服务端禁用策略保持生效，内部SQLite迁移继续原生运行。修正既有SDK工具结束测试将Inbox读取误当消息读取的夹具，不改变该测试验证的工具收尾结果。

原生canonical check36工作区通过；16个改动GUI文件严格lint零问题。独立typecheck:e2e仍为14条既有诊断，逐条对比无新增，不能记成通过。完整任务证据见[主题验收](../../upstream/theme-verification.json)、[checkpoint](../../upstream/theme-checkpoint.json)和[换肤前基线](../../upstream/theme-baseline.json)。性能基线及R4-01历史证据继续锚定595905d0，不重绑到当前主题源码。
