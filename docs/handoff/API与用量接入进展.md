## API与凭据

设置 → Providers → Add compatible API，填写独立连接ID、名称、HTTP(S)根地址及一个初始模型的实际上下文/输出上限；保存后复用原有账号/Key弹窗。固定内建openai-compatible适配器，不接受任意包、脚本、文件路径或插件。不假定1M、推理能力和价格。地址不允许userinfo、query或fragment；已有内建/配置ID返回409。新连接不会静默重定向旧会话模型或待发输入。

配置复用原生Config更新锁、JSONC编辑和reload，保留原文件注释及其他字段；管理模式只写自身显式私有配置。Key仅进入原生Credential/SQLite，不进入配置、公开目录、凭据事件或服务输出。通用config/shell/项目文件能力仍裁剪。客户端由原生generate生成，保留原生生成器的兼容别名规则。

目录发现入口仍是opencode/packages/im-assistant的models CLI：stdin JSON接收baseURL和可选apiKey，按需查询/models，输出去重ID和generationVerified:false。密钥不进命令参数，错误不回显响应正文或非法地址，不跟随重定向、重试或后台轮询。目录与生成分别验证；GUI当前手工添加一个初始模型，编辑/移除连接及GUI发现目录尚未实现。

## 用量与原生上下文

TokenUsage可选provenance在归零前保留适配器有效计数字段；旧记录或未报告不当作零。cost来源区分上游报告、目录估算、不可用和混合，报告零有权威性，金额只作参考，不作为套餐账单。

复用已有SessionEvent.UsageRecorded、原生Bus/EventTable事务和SQLite：管理模式仅额外保留辅助用量事实，没有开启完整事件日志、建立第二套账本或后台统计轮询。标题、压缩及临时生成的已返回用量都有来源和模型归属。临时生成只更新计量，不插入聊天消息、不消费待发输入、不改写指令或上下文。所有原生投影仍按原来的事务运行。

stats读取assistant步骤及辅助用量事实，按实际时间范围、项目和模型汇总；模型steps仍仅指assistant步骤，辅助用量不伪装成新回复或重复计入压缩消息。累计范围包含只有辅助调用的会话；分支创建前的继承记录不重复计数。旧辅助事件无模型时只进入总量，不猜测归属。原生部分日志保留不是可完整重放的事件档案；导出、消息和Inbox仍使用原机制。

新版设置 → Usage，提供今天、最近7个日历日（含今天）、累计与手动刷新；只在页面激活或操作时查询，离开不轮询，迟到响应不覆盖新范围。展示token、缓存命中、报告覆盖和各字段明细；缓存比例须输入/缓存细分齐全且分母大于零。完整记录按逐条交集计算。历史未保存、上游未报告、失败/重试中未返回的消耗无法还原，不能虚称为已知零或完整供应商账单。
