## 模型发现入口

在 opencode/packages/im-assistant 中使用锁定Bun执行 `bun run src/cli.ts models`，从标准输入接收JSON的baseURL与可选apiKey。请求API根地址下的/models，输出去重ID与generationVerified:false；不切默认模型、不变更队列、不假设1M上下文、思考能力或价格。密钥不进命令参数，错误不回显响应正文或原始非法地址；不跟随重定向，无重试或后台轮询，超时10秒。

`python -m tools.provider_discovery_smoke` 使用本地合成API，先查询目录且不生成，再单独由真实管理模式会话生成、写SQLite和重启恢复；统计来源信息也实际通过HTTP核对。没有验证用户的真实Agent2API账号。

## 原生用量与统计

TokenUsage.Info的可选provenance在归零前记录适配器提供的有效计数字段；旧历史缺省仍未知。cost来源区分reported/catalog/unavailable/mixed，合并不会把未知恢复成已报告。原生optional编码保持HTTP和事件类型一致，客户端由正常generate流程生成。

stats仍用原有SQLite查询，没有第二套账本。新增总体与逐模型reporting：记录数、所有字段完整的记录数、每个字段报告数，以及各费用来源的记录数与金额。完整记录按每条记录核对，不能用各字段报告数量的最小值冒充交集。历史缺失不当作已验证零。

新版设置 → Usage，提供今天、最近7个日历日（含今天）、累计和手动刷新。页面仅激活或操作时查询，离开不轮询，迟到响应不覆盖新范围；无异步Suspense读取。紧凑展示记录token、缓存命中和报告完整性，下方列输入、输出、推理和缓存明细。缓存命中仅在全部记录的输入/缓存细分齐全、分母大于零时显示；缺失显示Unknown。USD参考金额分上游报告、目录估算和未分类，不当作套餐账单。

## 本轮：兼容API配置与原生凭据接入

设置 → Providers → Add compatible API，填写独立连接ID、名称、HTTP(S)根地址和一个初始模型的实际上下文/输出上限；不自动假设1M、推理能力或价格。保存后调用原有账号/Key弹窗。API Key仅走原生Credential/SQLite，不进入配置、公开目录和服务输出。手工模型创建不代表目录已发现或真实生产模型已验证。

POST /api/experimental/config/provider仅接受元数据，固定使用内建openai-compatible适配器，不接收任意包、脚本、插件或路径。地址不允许userinfo、query和fragment；重复/已有内建provider ID返回409。配置复用原生Config更新锁、JSONC编辑和reload，保留原文件注释及其他字段；管理模式写入自身唯一显式私有配置。通用配置/shell等裁剪入口仍返回403。生成的客户端由原生generate产生，保留原生生成器的兼容别名规则。

python -m tools.provider_configuration_smoke使用真实管理模式HTTP服务和SQLite，仅模型端点是本地合成HTTP：必须携带保存的Bearer key才会返回结果。验证配置和Key重启恢复、重复ID/不安全地址/限额拒绝、旧会话模型与待发输入不变化、重启后真实生成、Key不进配置/公开目录/服务日志。无真实账号请求，未重启生产客户端。
